Project 2: Maps

CS 1332: Data Structures and Algorithms

Hash maps, balanced trees, and a duck registry database

Project 2 implements two map data structures from scratch and uses them, without any Java-provided maps, to build DaleDB. DaleDB tracks ducks, fish, and cows moving between ponds and evicts records for inactive ponds.

Parts

HashMap

Hash map with collision handling and resizing.

TreeMap (AVL)

Ordered map backed by a self-balancing AVL tree, using rotations to keep operations at O(log n).

DaleDB

Registry that records pond entries and exits and fish reports, answers queries about activity, and evicts inactive ponds.
