Project 1: Find George

ECE 2035: Programming for Hardware/Software Systems

Variably scaled exact-match detection in a crowd image

The task is to find one face, George P. Burdell, in a 64x64 crowd image where every face can be scaled by a factor of 2 to 5. The routine has to run in real time with minimal computation and storage while never missing George or flagging the wrong face.

Parts

P1-1: C Implementation

Graded on accuracy. Finds a face, measures its edges to get the scale, then checks key pixels against George's distinguishing features.

P1-2: RISC-V Assembly

The same algorithm in assembly, graded on accuracy and efficiency. Scans only every 12th row and 3rd column, skips to the edge of a face once it fails, and uses the mouth to determine scale.

Key Concepts
